Проект содержит 2 режима работы:

1) Демонстрация алгоритмов
Файл: sort.cpp
Показывает работу bubble_sort и quick_sort и выводит статистику (comparisons, swaps, moves).

Для запуска:
- включить sort.cpp в сборку
- исключить sort_test.cpp

2) Модульные тесты
Файл: sort_test.cpp
Содержит тесты для обеих сортировок (Google Test).

Для запуска:
- включить sort_test.cpp в сборку
- исключить sort.cpp

Примечание:
Оба файла содержат точку входа main, поэтому одновременно собираться не могут.
